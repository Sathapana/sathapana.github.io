02. Projets

reliability-lab : peut-on se fier à un juge LLM ?

Bibliothèque Python open source · 2026

L'alpha de Krippendorff existe déjà en Python ; cette bibliothèque ajoute le protocole d'étude autour du coefficient, pour les juges LLM comme pour les annotateurs humains. Chaque annotation porte un statut explicite (abstention, erreur de parsing ou d'API), le désaccord est détaillé en « boîte blanche », les intervalles bootstrap nomment leur schéma de rééchantillonnage et ont été vérifiés par simulation sur 26 scénarios, deux configurations de juge se comparent avec un intervalle apparié, et des découpages respectant les groupes mesurent la fiabilité sur des unités jamais vues pendant le réglage.

  • Alpha de Krippendorff
  • Fiabilité inter-annotateurs
  • LLM-as-a-judge
  • Bootstrap
  • Simulation
  • Package Python

Anomalies cachées dans le climat d'une serre

Projet de recherche personnel · 2026

Température, humidité et CO₂ peuvent chacun paraître normaux alors que leur combinaison est impossible. Une étude « boîte blanche » de 15 détecteurs multivariés sur six compartiments de serre, de la distance de Mahalanobis à une carte de contrôle sur résidus de contexte : un protocole figé, chaque alarme expliquée par variable et un test de déploiement sur données passées uniquement.

Risque de krach des penny stocks américaines

Projet de recherche personnel · 2026

Pour une small cap américaine volatile, un jour donné, quelle est la probabilité d'un krach dans les 20 séances suivantes, et peut-on la prédire mieux qu'une prévision de volatilité ? Une étude de survie pré-enregistrée sur 590 000 jours-actions, avec validation chronologique et un test final exécuté une seule fois.
