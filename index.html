02. Projects

reliability-lab: how far can you trust an LLM judge?

Open-source Python library · 2026

Problem
Krippendorff's alpha libraries return a single coefficient, but a reliability study of LLM judges or human annotators also needs failed ratings handled explicitly, honest intervals and leakage-safe splits.
Solution
An open-source Python library on PyPI that wraps alpha in the full study design: an explicit status for every rating, white-box disagreement, named bootstrap schemes, paired comparison of two judge configurations, group-safe splits.
Impact
Its 95% intervals hold up in simulation (93–95% coverage), where the classic KALPHA intervals are too narrow, covering only 70–90% with three or more annotators. Tested on 3 OSes × 3 Python versions in CI.

Hidden anomalies in a greenhouse climate

Personal research project · 2026

Problem
A sensor or control fault can keep temperature, humidity and CO₂ each inside its normal band while their combination is impossible, so per-variable alarms stay silent.
Solution
A white-box detector, a MEWMA control chart on context residuals, that checks the climate against what lamps, weather and set-points imply and names the variable behind each alarm. Chosen from 15 detectors under a frozen protocol on six greenhouse compartments.
Impact
Catches faults that per-sensor alarms miss: 7 of 7 real faults found, the responsible variable named in 91% of alarms. Refitted weekly, false alarms stay at 1.7% (target 1%), against 41% for a model never refitted.

Crash hazard in US penny stocks

Personal research project · 2026

Problem
For a volatile US small cap on a given day, what is the probability of a crash within 20 trading days, and does anything predict it better than a volatility forecast?
Solution
A pre-registered survival study on 590,000 stock-days: a discrete-time hazard on 22 frozen features against a volatility-forecast baseline, with time-ordered validation and a holdout run once.
Impact
Skipping each day's 10% of stocks the model ranks riskiest cuts the average loss of the worst 5% of trades by 3 points on the holdout. It reduces risk; it doesn't make money.
